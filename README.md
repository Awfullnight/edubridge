CounselorHub — Admission & School Profile

Веб-презентация проекта CounselorHub (платформа для школьного советника Maktab maslahatchisi и старшеклассников 9–11 классов: профориентация RIASEC, трекер IELTS/SAT, список вузов Reach/Match/Safety, портфолио и конструктор School Profile).

Файлы в репозитории

index.html — анимированная веб-презентация (8 слайдов, навигация кнопками, клавиатурой и свайпами, автопоказ, полноэкранный режим).

README.md — описание проекта и инструкция по публикации.

Как загрузить на GitHub и опубликовать на Vercel

Создайте Public-репозиторий на GitHub и загрузите туда index.html и README.md через Add file → Upload files.

Войдите на Vercel через аккаунт GitHub, нажмите Add New → Project, выберите репозиторий и нажмите Deploy.

Откройте полученную ссылку https://<ваш-проект>.vercel.app в любом браузере на телефоне или компьютере.

Управление слайдами

Кнопки / точки: переключение слайдов в нижней панели.

Клавиатура: ← / → или Пробел.

Сенсорный экран: свайпы влево и вправо.

Режимы: ▶ Авто — автопоказ, ⛶ — полный экран.
